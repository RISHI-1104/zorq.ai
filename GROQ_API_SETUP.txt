2️⃣ GETTING YOUR API KEY
=========================

Step 1: Create Account
   1. Go to: https://console.groq.com
   2. Sign up (or log in if you have an account)
   3. Verify email

Step 2: Create API Key
   1. In console, click "API Keys" in left sidebar
   2. Click "Create New API Key"
   3. Give it a name (e.g., "ZORQ AI")
   4. Copy the key (format: gsk_...)
   5. ✓ Save it somewhere safe!

⚠️  IMPORTANT: 
   - This key is SECRET - never share it
   - Never commit it to GitHub
   - Treat it like a password
   - Regenerate if compromised

3️⃣ INSTALLING IN ZORQ
=======================

METHOD A: Using .env File (RECOMMENDED for Production)
======================================================

1. Copy .env.example to .env:
   - Windows: Copy .env.example → Rename to .env
   - Or: copy .env.example .env (in terminal)

2. Edit .env file:
   GROQ_API_KEY=gsk_your_key_here

3. Update server.py to load from .env:
   ✓ Already supported if you use the setup.bat!

4. Restart server and test

METHOD B: Direct in Code (Quick Testing Only)
==============================================

1. Open: server.py
2. Find line ~8: GROQ_API_KEY = 'gsk_...'
3. Replace with your key:
   GROQ_API_KEY = 'gsk_YOUR_ACTUAL_API_KEY_HERE'
4. Save file
5. Restart server: python server.py

⚠️  SECURITY NOTE: This method is NOT recommended for production!
   Anyone who sees your code can steal your API key.

4️⃣ VERIFYING SETUP
===================

To verify your API key works:

Step 1: Start the server
   python server.py

Step 2: Open browser
   Go to: http://localhost:5000

Step 3: Test a message
   1. Complete authentication
   2. Type: "Hello! What's 2 + 2?"
   3. Send message

Step 4: Check results
   ✓ If you see response: "The answer is: 4" → Setup is working!
   ✗ If you see error: Check troubleshooting below

Optional: Check server logs
   1. Look at terminal where server is running
   2. You should see:
      [DEBUG] Received data: {'messages': [...]}
      [DEBUG] Sending X messages to Groq API
      [DEBUG] Response: "The answer is: 4"

5️⃣ TROUBLESHOOTING
===================

ERROR: "model does not exist or you do not have access"
-------------------------------------------------------
Solution:
1. Your API key might be invalid
2. Try a different model (see below)
3. Verify key at: https://console.groq.com/keys
4. Regenerate key if needed

ERROR: "Connection error" or "timeout"
--------------------------------------
Solution:
1. Check internet connection
2. Groq API might be down (rare)
3. Try again in a few seconds
4. Check server logs for details

ERROR: "Invalid API key"
------------------------
Solution:
1. Check there are no extra spaces in the key
2. Key should start with "gsk_"
3. Copy directly from console.groq.com
4. Regenerate new key and update

ERROR: 401 Unauthorized
------------------------
Solution:
1. API key is expired or revoked
2. Generate new key from console
3. Update GROQ_API_KEY in server.py
4. Restart server

6️⃣ SWITCHING MODELS
====================

Current Working Model (Tested):
   llama-3.1-8b-instant ✓ (Fastest, 8B parameters)

To switch models:

Step 1: Check available models
   https://console.groq.com/docs/models

Step 2: Update server.py
   Find line ~25:
   'model': 'llama-3.1-8b-instant',

   'model': 'mixtral-8x7b',

Step 3: Restart server
   python server.py

Step 4: Test in browser
   Send a test message and verify response

Popular Models:
   - llama-3.1-8b-instant ⚡ (Fastest, default)
   - mixtral-8x7b (More capable)
   - llama-3.1-70b (Very capable, slower)
   - gemma2-9b-it (Good balance)

Check console.groq.com/docs/models for full list and latest models.

7️⃣ SECURITY BEST PRACTICES
============================

Before Pushing to GitHub:
   ✓ API key should NOT be in any files
   ✓ Use .env for local development
   ✓ Add .env to .gitignore (already done)
   ✓ Check .gitignore includes: .env, *.env

For Production Deployment:
   ✓ Set environment variables on hosting platform
   ✓ NEVER hardcode API key in code
   ✓ Use .env.example as template (no real keys)
   ✓ Regularly rotate API keys
   ✓ Monitor API usage

Protecting Your Key:
   ✓ Treat like a password
   ✓ Don't share in messages/emails
   ✓ Regenerate if accidentally exposed
   ✓ Use limited-scope keys if available
   ✓ Check console for unusual activity
